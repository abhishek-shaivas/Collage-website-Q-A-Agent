Technologies Used
Python — Main programming language used to develop the application.
Gradio — Used to create the interactive web interface and navigation pages.
Requests — Used to send HTTP requests and download pages from the MITT website.
BeautifulSoup4 — Used to parse HTML and extract text and links from web pages.
Regular Expressions (Regex) — Used for text cleaning, URL processing, keyword matching, and sentence extraction.
URL Parsing (urllib) — Used to normalize URLs, identify domains, and discover internal website links.
Deque (collections) — Used to manage the website crawler's queue.
Keyword-Based Information Retrieval — Used to identify topics and find relevant website content.
Custom CSS & HTML — Used to create the black theme, colorful UI, cards, buttons, hero section, and responsive design.
